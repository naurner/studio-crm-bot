# Studio CRM Bot

CRM для фотоагентства выпускных фотоальбомов. Заказы живут в Google Таблице,
уведомления, распределение фотографов и claim-механика — в Telegram, задачи —
в Microsoft To Do.
Установка на домашний Mac — `docs/deployment-mac.md`.

## Настройка (один раз, в терминале)

1. Создать сервисный аккаунт в Google Cloud Console → включить Google Sheets API →
   скачать JSON-ключ.
2. Создать Google Таблицу с листом «Заказы» и строкой заголовков:
   `ID | Школа/класс | Контактное лицо | Телефон | Кол-во человек | Дата съёмки |
   Локации | Ответственный фотограф | Статус | Сумма контракта | Оплата | Примечания`.
   Лист «Съёмки» бот создаст сам.
3. Расшарить таблицу на email сервисного аккаунта (роль Editor).
4. Через @BotFather в Telegram создать бота и получить токен.
5. `python -m crmlumi setup` — Google Таблица и Telegram.
6. Зарегистрировать приложение в Azure AD (portal.azure.com → «Регистрация
   приложений» → «Мобильные и классические приложения», включить «Разрешить
   общедоступные клиентские потоки»), получить Client ID.
7. `python -m crmlumi todo-setup` — вход владельца и создание 6 списков To Do.
8. `python -m crmlumi install-service` — бот уходит в фон и сам поднимается
   после перезагрузки Mac. Терминал больше не нужен.

Либо то же самое в Docker, без установки Python в систему (шаги 5, 7 и 8
заменяются на три команды; часовой пояс задаётся переменной `TZ`):

    docker compose run --rm crmlumi python -m crmlumi setup
    docker compose run --rm crmlumi python -m crmlumi todo-setup
    docker compose up -d

Подробнее про оба варианта, обновление и переезд между ними —
`docs/deployment-mac.md`.

## Дальше — только кнопки в Telegram

Команды набирать не нужно: под полем ввода всегда есть кнопки, а в меню «/»
у каждого — только доступные ему команды.

| Кнопка | Кто видит | Что делает |
| --- | --- | --- |
| 📂 Заказы | все | заказы по этапам, «🔥 Ждут меня», карточка заказа |
| ➕ Новый заказ | владелец и «Приём заявок» | 4 вопроса → строка в таблице со статусом «Лид» |
| 📋 Списки To Do | все | ссылки-приглашения на списки одной кнопкой, привязка аккаунта Microsoft |
| ⚙️ Настройки | все | как часто напоминать о делах (3 ч … 3 дня, выкл) |
| ❓ Помощь | все | что умеет бот |
| 👥 Роли | владелец | кто за какой этап отвечает |
| 🖥 Хост | владелец | статус, обновление с GitHub, перезапуск, сроки этапов, лог, ссылки To Do, рассылка меню |

### Полный цикл заказа в боте

Таблицу открывать не нужно — всё из карточки заказа (📂 Заказы → этап → заказ,
или кнопка «📋 Открыть заказ» под уведомлением):

| Этап | Кто двигает дальше | Кнопка | Что бот спросит |
| --- | --- | --- | --- |
| Лид | Приём заявок | ✅ Договорились | сумму контракта (можно пропустить) |
| Договорились | Даты и локации | 📅 Съёмки назначены | съёмки: дата, время, локация (сколько угодно) |
| Дата и локация назначены | Даты и локации | 📸 Искать фотографов | — |
| Ищем фотографа | фотографы | «✋ Взять» на каждую съёмку; этап закрывается сам | — |
| Съёмка назначена | фотографы заказа | ✅ Съёмки проведены | — |
| Обработка фото | Обработка фото | ✅ Фото обработаны | — |
| Вёрстка | Вёрстка и согласование | ✅ Альбом свёрстан | — |
| Согласование с клиентом | Вёрстка и согласование | ✅ Клиент согласовал | — |
| Печать | Печать и выдача | ✅ Выдано клиенту | — |

- На каждом переходе следующий ответственный сразу получает уведомление,
  в To Do появляется задача нового этапа, а задача прошлого закрывается сама.
- ✏️ Изменить — поля заказа (ответственный за этап и владелец), 💰 Оплата — выбор кнопкой.
- Владелец может всё: двигать любой этап, «⬅️ Этап назад», «🔀 Выбрать этап».

### Материалы по цепочке

| Кто закрывает этап | Бот спрашивает | Кто сразу получает |
| --- | --- | --- |
| фотограф — «✅ Съёмки проведены» | ссылку на исходники | «Обработка фото» |
| обработка — «✅ Фото обработаны» | ссылку на обработанные фото | «Вёрстка и согласование» |
| вёрстка — «✅ Альбом свёрстан» | ссылку на макет | вёрстка (для согласования), потом «Печать и выдача» |

- Ссылки записываются в колонки «Ссылка на исходники», «Ссылка на обработанные»,
  «Ссылка на макет» (бот добавит их в таблицу сам), видны в карточке заказа и в
  задаче To Do следующего этапа.
- Ссылку можно пропустить и прислать позже: «✏️ Изменить» → нужная ссылка. Если
  заказ уже на этапе, которому она нужна, её сразу получат. Фотограф заказа может
  выложить исходники в любой момент.

### Удаление заказа

Владелец: карточка заказа → «🗑 Удалить заказ» → подтвердить. Удаляются строка в
таблице, съёмки заказа и его задачи в To Do; фотографам, взявшим съёмки, приходит
сообщение об отмене. Строку, удалённую из таблицы руками, бот тоже забывает.

### Съёмки

- У заказа сколько угодно съёмок, у каждой своя дата, время и локация
  (карточка заказа → 📍 Съёмки). Лежат на листе «Съёмки»; колонки «Дата съёмки»,
  «Локации», «Ответственный фотограф» в «Заказах» бот заполняет сводкой.
- Дата и время — календарём и кнопками часов/минут или текстом: 12.10 10:00,
  12.10.2026, завтра 15:30, 12 октября в 10:00, пт 11:00.
- Каждая съёмка — отдельная работа: фотографам приходит «📸 Нужен фотограф» по
  каждой, «✋ Взять» закрепляет её за нажавшим первым, «🚫 Отказаться» возвращает
  в рассылку. Владелец может назначить фотографа сам.
- Перенесли, сменили место, отменили или передали другому — фотограф получает
  сообщение сразу.
- Съёмки добавляет и переносит «Даты и локации» (на любом этапе) и владелец.

### Сроки и напоминания

- Задача в To Do на каждую взятую съёмку: срок — день съёмки, напоминание To Do
  за 2 часа. Перенесли — задача обновляется, отказались — удаляется.
- У задач этапов срок = начало этапа + N дней (🖥 Хост → ⏱ Сроки этапов;
  по умолчанию Лид 1, Договорились 3, Обработка 7, Вёрстка 5, Согласование 3,
  Печать 7). В карточке заказа видно «до …» или «просрочен на … дн.».
- Напоминания о делах: каждый выбирает частоту в ⚙️ Настройки (по умолчанию раз в
  день). Одно сообщение со всеми заказами, где ждут тебя, с 9:00 до 21:00.
- Фотографам: в 20:00 — расписание на завтра, в воскресенье — на неделю вперёд,
  за 2 часа до съёмки — напоминание. Время — по часам Mac. Часы и интервалы
  меняются в config.yaml → 
eminders.
- В любой роли может быть сколько угодно людей: 👥 Роли → роль → нажимать на
  людей, чтобы добавить или убрать.

### Остальное

- Новый человек пишет боту `/start` → получает кнопки и ссылки на списки To Do,
  владельцу приходит «новый участник» с кнопкой «Назначить роль».
- Когда владелец назначает или снимает роль, человек сразу получает сообщение
  и обновлённые кнопки.
- Ссылки-приглашения на списки To Do владелец добавляет в боте:
  🖥 Хост → 🔗 Ссылки To Do → выбрать список → прислать ссылку.
- Обновление: запушить код в GitHub → 🖥 Хост → 🔄 Обновить с GitHub. Бот сам
  скачает код, установит и перезапустится.
- Любой диалог прерывается кнопкой «✖️ Отмена».
